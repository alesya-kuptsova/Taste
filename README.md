# ✨ Taste

**Your wishes. Your collection. Your taste.**

Taste is a personal wishlist app for iOS and macOS that helps you collect and organize things you want to watch, read, buy, visit, or experience.

Save movies, books, games, music, places, products, and personal wishes in one collection.

## 🛠 Tech Stack

* **Frontend:** Swift, SwiftUI
* **Backend:** C#, ASP.NET Core Web API (.NET 8)
* **AI:** OpenAI API
* **Data:** TMDB, OpenStreetMap / Nominatim
* **Storage:** Local JSON persistence

## ✨ Current Features

* AI-powered item recognition from text and images
* Visual wishlist with a horizontal carousel
* Item detail screens
* Recently added items
* Full collection with category filtering
* Local wishlist persistence

## 🚧 Project Status

Taste is a personal pet project currently under active development.

Upcoming features include improved content recognition, sharing individual wishes and collections, and further iOS optimization.
